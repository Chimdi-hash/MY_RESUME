# My Resume — Futuristic Glassmorphic Portfolio

> A professional, futuristic portfolio/resume for a Full-Stack Software Engineer. Built with pure HTML, CSS, and Vanilla JS — no frameworks required.

## 🚀 Live Demo

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Chimdi-hash/MY_RESUME)

## ✨ Features

- 🌑 **Dark glassmorphic design** — `backdrop-filter` blur cards with glow effects
- ⚡ **Particle network background** — animated canvas particles with connecting lines
- ⬡ **Hexagonal project cards** — CSS `clip-path` hex grid with category filtering
- 🔤 **Typing effect** — rotating phrases in the hero section
- 📊 **Animated skill bars** — scroll-triggered progress reveals
- 🔢 **Counter animation** — hero stats count up on load
- 📱 **Fully responsive** — Desktop, Tablet, and Mobile layouts
- 🎯 **AOS animations** — custom scroll-triggered entrance effects
- 🖱️ **Cursor glow** (desktop) — radial glow follows mouse movement
- 📬 **Contact form** — with validation and simulated submission

## 📋 Sections

| Section | Description |

## 🚢 Deployment

### Deploy to Vercel (Recommended)
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repo `Chimdi-hash/MY_RESUME`
4. Click **Deploy** — Vercel auto-detects it as a static site ✅

### Run Locally
Just open `index.html` directly in your browser — no build step needed.

## ✏️ Customization

Edit `index.html` to update:
- **Your name** — find `Your Full Name`
- **Email & phone** — find `your@email.com` and `+234 000 000 0000`
- **Profile photo** — replace `profile.jpg` with your actual photo (3:4 portrait)
- **Job experience** — update company names, roles and achievements
- **Projects** — update hex card titles, descriptions and links
- **Education** — update degrees and school names
- **Social links** — update GitHub, LinkedIn, Twitter URLs
